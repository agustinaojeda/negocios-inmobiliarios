**Negocios Inmobiliarios** es una plataforma web integral diseñada para conectar a inquilinos, propietarios y agentes comerciales en un mismo entorno digital. Combina la búsqueda inteligente de inmuebles con herramientas analíticas, simulación de costos y agendamiento de visitas para optimizar la gestión inmobiliaria.

---

### Características Principales

- **Búsqueda y Filtros Avanzados:** Catálogo dinámico con filtrado por ubicación, tipo de propiedad y modalidad (alquiler/venta).
- **Simulador de Aumentos de Alquiler:** Calculadora en tiempo real para estimar reajustes de contratos mediante la integración con la API de *arquiler.com*.
- **Solicitud y Agenda de Turnos:** Coordinación de visitas presenciales para propiedades entre usuarios interesados y agentes comerciales.
- **Panel de Administración & Métricas:** Dashboard centralizado para gestión del catálogo general, control de citas e indicadores clave (estadísticas de rendimiento de inmuebles, agentes y operación general para la toma de decisiones).

---

### Stack Tecnológico

- **Frontend:** [React](https://react.dev/) / [Next.js](https://nextjs.org/)
- **Backend:** [Node.js](https://nodejs.org/)
- **Base de Datos:** [PostgreSQL](https://www.postgresql.org/)
- **Lenguaje:** JavaScript
- **Integraciones:** API de [arquiler.com](https://arquiler.com/)

---

### Instalación y Configuración Local

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/agustinaojeda/negocios-inmobiliarios.git](https://github.com/agustinaojeda/negocios-inmobiliarios.git)
   cd negocios-inmobiliarios
   ```
2. **Instalar dependencias:**
   ```bash
   npm install
   ```
3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
4. **Acceder a la aplicación:**
   Abre tu navegador e ingresa a http://localhost:5173 (o el puerto configurado en consola).
